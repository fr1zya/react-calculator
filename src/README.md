# Калькулятор на React

Это первый полноценный веб-проект, созданный с помощью библиотеки React. Приложение представляет собой калькулятор.

## Технологии

*   **React:** Для создания пользовательского интерфейса и управления состоянием.
*   **CSS:** Для стилизации. Использованы современные подходы:
    *   **CSS Grid** для раскладки кнопок.
    *   **Flexbox** для идеального центрирования калькулятора на странице.
*   **Git & GitHub:** Для контроля версий и публикации проекта.
